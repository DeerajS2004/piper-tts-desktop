# 🎤 Piper TTS Desktop Application

A modern desktop Text-to-Speech application using Piper TTS engine.

## ✨ Features
- 🎵 High-quality offline TTS
- 🎨 Modern GUI with toolbar interface
- ⌨️ Full keyboard shortcuts support
- 📍 Position marking & jump-to-mark
- ⚡ Speed control (0.5x to 2.0x)
- 🔊 Multiple voice support
- 🖥️ Desktop integration (App Menu entry)

## 🚀 Installation
```bash
# Clone this repository
git clone https://github.com/DeerajS2004/piper-tts-desktop.git
cd piper-tts-desktop

# Run the installer
./scripts/install.sh
